# Security Policy

## Supported Versions

FixFlow actively maintains security fixes for the latest release:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of FixFlow seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report vulnerabilities by contacting the maintainers or opening a private security advisory through GitHub:

1. Navigate to the repository's **Security** tab.
2. Click **Report a vulnerability** under **Advisories**.
3. Provide:
   - Description of the vulnerability
   - Steps to reproduce or proof-of-concept
   - Impact assessment
   - Any proposed fix or mitigation

### Response Timeline
- **Initial Response:** Within 48 hours of receipt.
- **Status Update:** Regular updates every 3 business days while investigating.
- **Resolution:** A patch will be published as soon as verification is complete.
